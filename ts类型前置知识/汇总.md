## ts 类型系统

ts 是一个图灵完备的编程语言，它的类型系统非常强大，支持下面这些类型操作将一个已有类型表达为另一个新的类型。

- Generics：[泛型](https://www.typescriptlang.org/docs/handbook/2/generics.html)
- Keyof Type Operator：[Keyof 类型操作符](https://www.typescriptlang.org/docs/handbook/2/keyof-types.html)
- Typeof Type Operator：[Typeof 类型操作符](https://www.typescriptlang.org/docs/handbook/2/typeof-types.html)
- Indexed Access Types：[索引访问类型](https://www.typescriptlang.org/docs/handbook/2/indexed-access-types.html)
- Conditional Types：[条件类型](https://www.typescriptlang.org/docs/handbook/2/conditional-types.html)
- Mapped Types：[映射类型](https://www.typescriptlang.org/docs/handbook/2/mapped-types.html)
- Template Literal Types：[模版字面量类型](https://www.typescriptlang.org/docs/handbook/2/template-literal-types.html)
