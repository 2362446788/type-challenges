# tags

按标签整理 `easy` 和 `middle` 题目，原始题目目录保持不变。

标签主要参考官方仓库 README 的 `By Tags` 分类；另外补了两个本地兼容标签：

- `warm-up`：用于本地 `1-Hello-World`。
- `custom`：用于本地自定义题，例如 `0-Infer`、`10000-WonType`。

兼容映射：

- `1-Hello-World` 按官方 `13 Hello World` 归类。
- `629-Absolute` 按官方 `529 Absolute` 归类。
- `654-Diff` 按官方 `645 Diff` 归类。
- `4472-Zip` 按官方 `4471 Zip` 归类。
